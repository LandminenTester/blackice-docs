# BlackICE-Ressourcen

Hier findest du die Dokumentation für die BlackICE-Werkzeuge, Bundles und Dienste von LandminenTester. Jede Ressource hat eine eigene Einrichtung, Konfiguration, Betriebsanleitung und Referenz.

| Ressource | Aufgabe | Einstieg |
| --- | --- | --- |
| BlackICE Server Panel | Eigenständige Weboberfläche für Server, Konsole, Benutzer und Bundles | [Übersicht](webpanel/README.md), [Betrieb](webpanel/docs/operations.md) |
| lt_database | Server-Bundle für Datenbankzugriffe; benötigt lt-database-api | [Installation](lt-database/docs/INSTALL.md), [C#-Nutzung](lt-database/docs/USAGE.md), [Praxisbeispiel](lt-database/docs/EXAMPLES.md) |
| lt-database-api | HTTP-Dienst vor PostgreSQL, MySQL/MariaDB oder MongoDB | [Bereitstellung](lt-database-api/docs/DEPLOYMENT.md), [API](lt-database-api/docs/API.md) |

Das Panel ist eine separate Ressource. Nur Connector und Datenbank-API benötigen einander für die Bundle-Anbindung. Es gibt keine vorgeschriebene gemeinsame Installation aller Ressourcen.

Lies die [ersten Schritte](getting-started.md), den [Datenbank-Schnellstart](database-quickstart.md) oder das [Begriffsverzeichnis](glossary.md). Englisch ist die Standardsprache; die Sprachauswahl im Kopfbereich führt zur entsprechenden englischen Seite.

# Sicherheitsprobleme melden

Sicherheitslücken bitte über [private GitHub-Sicherheitsmeldungen](https://github.com/LandminenTester/lt-database-api/security/advisories/new) melden. Keine Secrets, Datenbankpasswörter oder ausnutzbaren Details in öffentliche Issues schreiben.

Nenne Version beziehungsweise Commit, Plattform, minimale Reproduktion, erwartete Auswirkung und bereinigte Nachweise. Betroffene Schlüssel bei einem vermuteten Leak widerrufen und Logs sowie Journale geschützt für die Untersuchung aufbewahren.

Die neueste unterstützte Version verwenden und vor produktivem Betrieb [Sicherheitsdesign](docs/SECURITY.md) sowie [Bereitstellung](docs/DEPLOYMENT.md) lesen. Das Projekt bietet keine zugesicherte Reaktionszeit oder unabhängige Sicherheitsprüfung.

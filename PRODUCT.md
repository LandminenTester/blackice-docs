# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Owners and developers of BlackICE servers looking for LandminenTester bundles and resources, their setup guides,
configuration, operation instructions and API references.

## Product Purpose

A public documentation library for all LandminenTester BlackICE resources. Each resource is independently documented.
The panel is a separate resource. Only the database connector and its database API have a required relationship.

## Capabilities and Constraints

Keep the existing product guides, examples, search, navigation, source attribution and public access. Content remains
Markdown compatible with GitBook Git Sync. The deployed site uses MkDocs and GitHub Pages. More resources must fit
without changing the premise of the homepage. No account, database or game server is required to read documentation.

## Brand Commitments

The user requests a modern, sleek cyberpunk visual identity and complete removal of the database bundle's previous naming.
Use `lt_database` for the bundle. The API is `lt-database-api`. The publisher remains LandminenTester.

## Evidence on Hand

Real product guides and compiled examples under content/, source commit provenance in content/sources.json,
and public release links. No marketing claims, invented statistics or resource dependency on the panel.
